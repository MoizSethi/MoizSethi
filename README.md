## 🚀 Featured Projects

### 🏋️ Gymora — Gym Management ERP & SaaS Platform
A multi-role fitness operations platform for **gym owners, trainers, and members**.

**Highlights:**
- Membership & member management
- QR-based attendance and check-in workflows
- Trainer workspace and scheduling
- Workout and nutrition programming
- Lead management and retention insights
- Reporting and operational analytics
- Web and mobile experiences

**Stack:** React · Node.js · TypeScript · MySQL · REST APIs · Flutter

### ☎️ DialSync — Cloud Dialer, CRM & Sales Automation Platform
A cloud-based calling and sales operations platform designed for high-volume outreach teams.

**Highlights:**
- RingCentral integration
- Campaign and lead management
- Automated calling queues
- Role-based access control
- Call history and dispositions
- Agent workflows and caller management
- Performance analytics and reporting

**Stack:** React · Node.js · TypeScript · MySQL · REST APIs · RingCentral · Docker

### 🤖 Prime Med AI Agent — Healthcare Automation Platform
An automation and data-processing platform built around healthcare provider discovery and operational workflows.

**Highlights:**
- NPI / NPPES data processing
- Provider matching and revalidation workflows
- Contact-data enrichment
- Automated lead-generation workflows
- Local database and bridge architecture
- Scheduled data-processing pipelines

**Stack:** Python · Streamlit · SQLite · REST APIs · Automation Workflows
